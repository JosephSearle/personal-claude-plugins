# Interview scorecard

Give every interviewer the same questions and the same bar.

## Inputs

The job advert or role brief, and the interview stages. Ask which stage this scorecard is for if more than one exists.

## Process

1. Pick four to six competencies from the role's must-haves.
2. For each competency write:
   - one behavioural question ("Tell me about a time...")
   - one follow-up probe
   - what a 1, 2, 3 and 4 answer looks like, as observable evidence
3. Add an overall recommendation: Strong no, No, Yes, Strong yes.
4. Add a notes field per competency for evidence, not impressions.

## Rules

- Rate each competency before the overall recommendation.
- No questions about protected characteristics, family plans or health.
- No candidate names or personal details in the template.

## Output

A Markdown table per competency, then the recommendation section.
