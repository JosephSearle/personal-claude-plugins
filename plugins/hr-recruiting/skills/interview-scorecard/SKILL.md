# Interview scorecard

Build a scorecard so every candidate for a role is assessed against the same criteria. Apply the `data-handling` skill: never put candidate names or details in the scorecard.

## Inputs

- Job title and level
- Four to six competencies the role needs (propose them from the advert if not given)
- Interview format and length

## Process

1. List the competencies, each with a one-line definition.
2. For each competency, write two questions: one behavioural ("Tell me about a time…") and one situational ("What would you do if…").
3. Write scoring anchors on a 1–4 scale:
   - 1: No evidence
   - 2: Partial evidence
   - 3: Meets the bar
   - 4: Exceeds the bar
4. Describe what a 3 looks like in one sentence per competency.
5. Add a notes field and a final recommendation field (Hire, No hire, Discuss).

## Rules

1. Ask every candidate the same core questions.
2. Do not ask about age, family plans, health, religion, nationality or other protected characteristics.
3. Score each competency before the overall recommendation.
4. Score on evidence stated in the interview, not on impressions.

## Output

A table: competency, definition, questions, anchors. Then a blank scoring sheet the interviewer can copy.
