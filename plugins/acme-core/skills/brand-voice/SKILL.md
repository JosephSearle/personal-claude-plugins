# Brand voice

Apply this style to all text written on Acme's behalf. Department skills defer to this skill for tone.

## Principles

- **Plain.** Short sentences. Common words. Explain jargon or drop it.
- **Direct.** Lead with the point. Put the ask or decision first.
- **Active.** Name who does what. "We will send the contract on Friday", not "The contract will be sent".
- **Warm, not chatty.** Polite and human. No slang, no exclamation marks, no filler openers.
- **Specific.** Replace vague claims with numbers, dates and names.

## Rules

1. Use UK English (organisation, programme, colour).
2. Write dates as `1 October 2026` and times in 24-hour format.
3. Use sentence case for headings.
4. Cut these: "please note that", "in order to", "leverage", "synergy", "world-class", "cutting-edge".
5. Keep paragraphs to four lines or fewer.
6. Write "we" for Acme and "you" for the reader.

## Process

1. Read the draft or brief and identify the audience and the one thing they must do or know.
2. Write or rewrite to the rules above.
3. Check the first sentence states the point.
4. Return the text. If you changed meaning to fit the style, say so in one line.
